# Contributing

1. Open an issue describing the change or problem.
2. Create a focused branch and make a small, testable change.
3. Keep feature engineering and model-serving behavior in `src/applied_ml/`.
4. Add or update tests for data validation, preprocessing, metrics, or API behavior.
5. Run `pytest` before submitting a pull request.
6. Never commit secrets, private datasets, or sensitive model artifacts.
